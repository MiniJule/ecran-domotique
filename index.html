Écran domotique

Application Android personnelle qui transforme un vieux téléphone posé sur un bureau en écran d'information, dans le style du mode StandBy d'iOS : heure, agenda, tâches, mails, musique de l'iPhone, météo et résumé du matin.

Cette application est un projet personnel, utilisé par son seul auteur sur son propre téléphone. Elle n'est pas distribuée au public et n'est disponible sur aucune boutique d'applications.

Elle utilise les API Google suivantes, uniquement avec le compte de son auteur :

  • Google Tasks : afficher les tâches et les cocher ;
  • Gmail (lecture seule) : afficher le nombre de mails non lus et leurs expéditeurs ;
  • Google Drive (fichiers créés par l'application seulement) : lire deux petits fichiers de l'application.
